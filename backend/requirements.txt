# upstream into EmilioVenegas/strider main, in order:
#   1. native-tm  : Rust/PyO3 accelerator (strider._native) for Tm/salt kernels   [PR #11]
#   2. native-dp  : native Rust port of the dimer MFE candidate DP                [PR #12]
#   3. mathews2004-dangles: corrected Mathews 2004 paramset (stack/bulge/interior
#      key conventions verified vs ViennaRNA eval), paramset threading on
#      hairpin/dimer APIs, name resolution, dangles=2 exterior stacks           [PR #13]
#   4. hairpin-behavior: 25C default fold, MIN_STEM_BP=3 guard (rejects hairpin
#      stems under 3bp instead of an unstable two-state Tm; matches

#      multiloop stem-loop splitting, dimer dangles=0|2 flag (default 0)       [PR #14]
